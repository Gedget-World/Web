## 3. Accessibility Features

We have implemented the following accessibility features on our website:

### 3.1 Navigation & Structure

| **Feature**                   | **Description**                                                                        |
| ----------------------------- | -------------------------------------------------------------------------------------- |
| **Keyboard Navigation**       | All interactive elements are accessible via keyboard (Tab, Enter, Arrow keys, Escape). |
| **Skip to Content Link**      | A "Skip to main content" link is provided to bypass repetitive navigation.             |
| **Consistent Navigation**     | Navigation menus are consistent across all pages.                                      |
| **Logical Heading Structure** | Proper heading hierarchy (H1, H2, H3) for screen reader navigation.                    |

## 12. Accessibility Features Quick Guide

### For Users Who Are Blind or Have Low Vision

- **Screen Reader Compatibility:** Our website works with NVDA, JAWS, VoiceOver, and TalkBack.
- **Alt Text:** All product images have descriptive alt text.
- **Headings:** Proper heading structure for easy navigation.
- **Skip Links:** Skip to main content link available.
- **Text Resize:** Text can be enlarged up to 200%.

### For Users Who Are Deaf or Hard of Hearing

- **Video Captions:** `⚠️ [UPDATE: "Available on all videos" / "Available on most videos"]`
- **Visual Indicators:** Important information is not conveyed by sound alone.
- **Text-Based Support:** Email and chat support available.

### For Users with Motor Disabilities

- **Keyboard Navigation:** All features accessible via keyboard.
- **Large Click Targets:** Buttons and links have adequate size.
- **No Time Limits:** `⚠️ [UPDATE: "No strict time limits" / "Time limits can be extended"]`
- **Reduced Motion:** Animations respect system preferences.

### For Users with Cognitive Disabilities

- **Clear Language:** Content written in plain, simple language.
- **Consistent Layout:** Predictable, consistent navigation.
- **Error Prevention:** Clear error messages with suggestions.
- **Search Function:** Easy-to-use search for finding products.
